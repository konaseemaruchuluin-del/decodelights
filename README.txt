DECO DELIGHTS BALLOON WEBSITE
================================

1. Extract the ZIP.
2. Open index.html in a browser.

PHOTO SLIDER
------------
The right-side hero area is already a working automatic slider.

Replace:
images/decor1.svg
images/decor2.svg
images/decor3.svg
images/decor4.svg

with your real photos.

If you use JPG files, change the four image names in index.html accordingly:
images/decor1.jpg
images/decor2.jpg
images/decor3.jpg
images/decor4.jpg

WHATSAPP
--------
Open index.html and replace:
https://wa.me/910000000000
with your real WhatsApp number in international format.

The website is responsive and includes mobile styling.
